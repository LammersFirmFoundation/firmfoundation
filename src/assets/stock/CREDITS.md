# Stock photography — sources and licenses

These are **not Firm Foundation's jobs**. They illustrate the kind of work each
service involves until Josiah's own photos replace them. Rules, so they stay
honest:

- **Never** in the Gallery ("Our Work"), never captioned as a project, and alt
  text describes only what is literally in the frame, never "our" anything.
- Josiah's real machine (`src/assets/services/excavation.jpg`) is in the
  homepage hero and leads the Excavation page. Stock never replaces it.
- Replace any of these with a real job photo the moment one exists: set
  `image` / `cardImage` in `src/data/services.ts` and delete the file here.

All licenses were checked on each photo's own page on 2026-09-29. Both allow
free commercial use with no attribution required. Neither lets these files be
sold unaltered or redistributed as a stock collection.
